# InteractiveShowcase Prototype 1 — 起動・確認・復旧

顔が約1秒続けて映ると円が緑になり、「こんにちは！」を約2秒表示します。顔が消えても挨拶は最後まで表示します。挨拶の終了と約1秒の退出を確認してから、次の体験を受け付けます。
抽選・スロット演出・音・3Dはこの版に含めません。

## 初回準備・起動

1. 配布ZIPを版ごとの新しいフォルダへ全て展開します。P0のフォルダに重ねて上書きしません。
2. Python 3.11 x64を用意し、`SetupVision.cmd` を実行します。初回のライブラリ取得にはインターネットが必要です。実行中はクラウド送信しません。
3. `CheckEnvironment.cmd` でPython依存・vision設定を確認します。カメラとP1の挨拶表示そのものを診断する機能ではありません。
4. `StartPrototype1.cmd` でアプリとPythonを起動します。配布版の `StartShowcase.cmd` も同じローカルexeを起動します。
5. 顔を約1秒映し、挨拶・緑色・追従を確認します。

終了：PythonのウィンドウでCtrl+C、Unityアプリを閉じます。二重起動しないでください。
映像を一時確認する場合は通常Pythonを終了してから `StartVisionPreview.cmd`（Qで終了）。画像を保存しません。

開発リポジトリでは `StartPrototype1.cmd` が `Builds/WindowsPrototype1Release/` を使います。従来の `StartShowcase.cmd` はP0の入口として維持しています。
Editorでは `Assets/Prototype1/Scenes/Prototype1.unity` を開いてPlayし、`StartVision.cmd` を実行します。Editorとアプリを同じUDPポートで同時起動しないでください。

## 設定

| ファイル | 内容 |
|---|---|
| config/vision.json | 既存のカメラ番号・ポート・反転・平滑化・通信タイムアウト |
| config/experience.json | detectionHoldSeconds=1、greetingSeconds=2、exitHoldSeconds=1 |

挨拶の時間は各0.1〜10秒です。型違い・不足・重複・不正値はエラーになり、挨拶を開始しません。設定変更後はアプリを再起動してください。
Editorはリポジトリ直下のconfig、Windowsアプリはexe横のconfigを使います。ビルド先の設定はビルド時点のコピーです。
円の位置・可視性は既存Follower、色と文字はP1 Controllerが管理します。日本語は同梱フォントで表示するため、PCへの追加フォントインストールは不要です。

## 目視確認（ユーザー担当）

| 操作 | 期待結果 |
|---|---|
| 顔を約1秒続けて映す | 緑の円と「こんにちは！」 |
| 挨拶中に顔を外す | 円は消えるが文字は約2秒の期限まで残る |
| 挨拶中にすぐ戻る | 円が追従復帰、文字の期限は延びない |
| 顔を映し続ける | 挨拶を繰り返さない |
| 挨拶終了後、約1秒退出して戻る | 新たに約1秒待って挨拶 |
| Pythonを停止・再開 | タイムアウト後に円・挨拶が消え、再開後に新しく開始判定 |

見やすさ・タイミング・反射・距離は自動試験で合格判定しません。P0の確認済み結果もP1へ自動転用しません。

## 困った場合

- 円は動くのに挨拶しない：一度1秒以上退出し、戻って1秒以上待つ。`config/experience.json` があり、全項目が正しいか確認。
- 円も動かない：Pythonのエラー、カメラ権限・番号、接続、他アプリによる占有、同じポートの二重起動を確認。
- 通信切断では通常退出と異なり、挨拶も中断します。最後の有効受信から既定0.5秒超で判断するため、停止瞬間の即時検出ではありません。
- カメラreadエラー：接続・権限・占有を直してPythonを再起動。画像や人物情報を提出する必要はありません。
- 設定を戻す：現在のconfigを退避し、同じ版のZIPからconfigを別の場所へ展開して戻す。
- 更新から戻す：新版を終了し、保存してある旧版を別フォルダで起動。既存版を削除する必要はありません。

画像保存・録画・個人識別・属性推定・クラウド送信は行いません。顔がない／あるだけで受付を制御するため、同じ人の再体験を禁止する機能や複数人の順番管理はありません。
