# InteractiveShowcase Prototype 0 — Windows配布版

Webカメラの顔位置に円形マーカーが追従する技術検証です。1人の顔のみ対応します。
顔画像の保存・録画・個人識別・年齢/性別/感情推定・クラウド送信は行いません。
PythonとUnityは同じPCの127.0.0.1へ座標だけを送ります。

## 初回準備

1. ZIPを通常の作業フォルダに全て展開してください。exeだけを移動しないでください。
2. Windows用Python 3.11 x64を用意します。検証版は3.11.9です。Unity Editorは不要です。
3. `SetupVision.cmd` を実行します。専用venvを作成し、固定した依存関係を取得します。
   初回のみインターネット接続が必要です。管理者権限やグローバルPythonの変更は不要です。
4. `CheckEnvironment.cmd` を実行します。これはカメラを開きません。
5. `StartShowcase.cmd` でUnityとPythonを起動します。初回のみWindowsのカメラ利用設定を確認してください。

Pythonを自動検出できない場合はPowerShellで、インストール済みPythonの実際のパスを指定します。

```powershell
.\Tools\SetupVision.ps1 -PythonExecutable 'C:\実際のインストール先\python.exe'
```

セットアップがセキュリティポリシーで拒否される場合は、Python 3.11の実行ファイルから
`vision/setup_environment.py` を直接実行できます。PC全体の実行ポリシー変更は不要です。

## 日常の操作

- 開始：`StartShowcase.cmd` を1回実行。二重に実行しないでください。
- 終了：PythonのウィンドウでCtrl+C、Unityのウィンドウを閉じます。
- 映像の確認：通常のPythonを終了してから `StartVisionPreview.cmd`。Qで終了します。
  通常送信とプレビュー送信を同時に実行しないでください。
- 顔がないとき、起動直後、Python停止時は暗い画面になります。顔があると円が表示されます。
- UDPポートの診断で「unavailable」はUnity起動中には正常です。相手のアプリの種類までは判定しません。

## 設定

`config/vision.json` を編集し、PythonとUnityの両方を再起動します。
カメラとUnityの設定を1ファイルで合わせます。送信先はlocalhostに固定です。

| 項目 | 初期値 | 意味 |
|---|---:|---|
| cameraIndex | 0 | カメラ番号。0〜99 |
| port | 5005 | UDPポート。1〜65535 |
| mirrorX | true | 鏡のような左右反転 |
| flipY | true | 画像の下向きYを画面の上向きYに変換 |
| smoothTime | 0.08 | 平滑化時間（秒）。0.001〜5 |
| timeoutSeconds | 0.5 | 有効データが途絶えたときの非表示までの秒数。0.1〜10 |

値を変える必要がなければ初期値を使ってください。設定の欠落・不正値はエラーで停止します。
プレビュー映像は左右反転しません。円のサイズは固定です。

## 問題が起きたとき

| 症状 | 確認・復旧 |
|---|---|
| Pythonを開けない | ZIPを全て展開したか確認。`SetupVision.cmd` → `CheckEnvironment.cmd` |
| Camera unavailable / read failed | 他のカメラアプリを閉じる。接続・Windowsのカメラ権限・cameraIndexを確認し、Pythonを再起動 |
| 暗いまま | 顔なしなら正常。Pythonのエラー、カメラ、両者が同じconfigを使うか、二重起動を順に確認 |
| UDPの起動エラー | Unityを二重起動していないか確認。終了後に1つだけ起動 |
| 設定を壊した | 原本ZIPのconfigだけを別フォルダへ展開し、現在のconfigを退避して戻す |
| 更新後に動かない | 新版を終了し、以前のZIPを別フォルダへ展開。以前の版でSetupVisionを実行して起動 |

既存版に新しいファイルを重ねて上書きせず、版ごとに別フォルダを使ってください。
`manifest.json` のバージョン・ソースcommitと、ZIPに添付するSHA-256で版を識別できます。
Pythonの依存関係取得先が利用できない場合、初回セットアップは完了しません。

## 確認範囲と制限

ユーザーは開発用PCのWindowsアプリで、実顔の追従・左右上下の方向・退出/再登場・体感遅延・約5分の連続動作を確認済みです。
この報告は整備前の動作確認版に対するものです。整備版は同じ設定値で機械的な回帰確認を行いますが、整備版の実顔試験や別PCでの動作を代わりに保証しません。
5分超の実カメラ動作、物理的な抜き差し、店頭・ショーケース・MSI実機・反射や照明への適性は未確認です。
検証用プローブは配布版に含まれません。顔を保存する診断機能もありません。
店舗での承認・掲示・機材の安全確認、常駐・自動起動はこの版の対象外です。
