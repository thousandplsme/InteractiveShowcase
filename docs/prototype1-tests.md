# Prototype 1 自動テスト計画

この文書は実装前に定めた期待結果です。2026-10-27の実施結果・根拠は [prototype1-results.md](prototype1-results.md) に記録します。
仕様は [実装計画](prototype1-plan.md) のR01〜R12を参照。

## 1. 試験方法

- 状態機械は単調増加する時刻を引数として受け取る。単体試験では疑似時刻を進め、実時間の待機を使わない。
- 単体試験の既定値は開始1秒・表示2秒・退出1秒。各値の直前／一致／直後を検査する。
- Unity統合試験では実際のController、Canvas、円、挨拶Textを使う。値を同じ式で計算するだけの試験ではなく、入力の時系列に対する開始回数・状態・表示を確認する。
- 実UDP試験はPythonのUdpSenderとUnity Receiverをそのまま使用する。顔なしを送り続けるケースと、子プロセスを強制終了して一切送信しないケースを分ける。
- テスト用ポートを使用する。実カメラは開かず、画像・実顔座標をログに残さない。ログは試験ID、人工指示、状態・回数・経過時間・合否に限定する。
- 状態の更新順は受信→体験判定→表示→観測。フレームが進んだことを確認して判定する。

## 5. Python→UDP→Unityの通し試験

実シーンを読み込んだEditorまたはWindows Developmentで実施。観測専用プローブは状態を変更せず、実装された処理の結果だけを見る。

| ID | 人工データのシナリオ | 合格条件 |
|---|---|---|
| E01 | 顔ありを継続 | 円が追従し、H後に挨拶1回、G後に通常表示。継続中は再発火しない |
| E02 | 挨拶直後に正常NoFaceを継続送信 | 円は消え、文字は最後まで残る。通信途絶と混同しない |
| E03 | 挨拶中／退出待ちで短いNoFace→再登場 | 該当する表示復帰を行い、挨拶を追加発火しない |
| E04 | 十分なNoFace→再登場を複数回 | サイクルごとに挨拶はちょうど1回。再登場後もHの待ちが必要 |
| E05 | 挨拶中に送信Python子プロセスを強制終了 | 受信タイムアウト後に文字・円を消し、Unityが進行し続ける |
| E06 | E05後に子プロセスを再起動 | Unity再起動なしで復帰し、H待って新しい挨拶。古い表示期限は使わない |
| E07 | 不正JSON・必須値不足・範囲外・非有限数・不正UTF-8・過大データを送信 | 有効受信期限を延長せず、途絶扱いへ。正常データで復帰 |
| E08 | 最後にNoFaceを1回送ってからPython停止 | 一時的なNoFaceの後は必ずタイムアウト。NoFaceを無期限の正常通信と誤認しない |
| E09 | 10分の人工体験サイクル | 正常開始・退出・再登場と予定した切断復帰の開始回数が一致。フレーム進行あり、例外・固まりなし |

時間の厳密な境界は単体試験で確認する。通し試験では実行時の更新間隔を記録し、表示反映には少数フレームの余裕を認める。通信の不調を隠すため無制限に待つことはせず、各段階に明示的な期限を設ける。
10分試験の時間はWindows Developmentでの人工データ時間として記録し、実顔・別PC・店頭での安定性とは区別する。

## 7. 結果の保存と終了条件

- 出力はGit対象外の `TestResults/prototype1/` 以下に、実行ごとに区別して保存する。
- 記録内容：実行したID、対象commit／dirty状態、Unity/Python版、設定値、結果、経過時間、合計開始回数、フレーム進行、エラー数。
- 実装時のテスト関数数はケース分割により変わり得る。ここでは要件ごとのシナリオを列挙しており、件数を実行実績として報告しない。
- 必須シナリオはS01〜S21、C01〜C05、U01〜U09、E01〜E09、B01〜B09。失敗・省略は理由と影響を記録する。
- 検証用子プロセスと自分で起動したアプリだけを終了し、一時的なポート・Play・timeScale・背景実行設定を復元する。
- 自動試験の成功と、実顔でのユーザー受入は別欄に記録する。

## 8. ユーザーが目視する項目

1. 約1秒待った反応、約2秒の文字表示が自然か。
2. 顔が消えても文字が最後まで残り、再登場で不自然な再発火がないか。
3. 横長のラップトップ画面で案内・挨拶・説明が読みやすいか。円が文字を邪魔しないか。
4. 実カメラの追従とPython停止／再開時の見え方が正常か。
5. 店頭の距離・照明で気づいてもらえるか。これは開発PCの自動試験では判断しない。
